# 电商用户行为画像与转化漏斗分析
 
## 项目简介
 
本项目基于电商平台用户行为数据，通过 SQLite + Python 技术栈实现全链路用户行为分析，核心覆盖转化漏斗计算、流失环节诊断、用户群体画像三大模块，通过 Matplotlib 完成可视化输出，定位转化流失的核心节点，为业务优化提供数据支撑。
 
## 技术栈
 
- 编程语言：Python 3
- 数据存储与查询：SQLite（内存数据库模式）
- 数据处理：Pandas、NumPy
- 数据可视化：Matplotlib
- 运行环境：Jupyter Notebook / 和鲸数据分析平台
 
## 项目结构
  
├── 电商用户行为画像与转化漏斗分析.ipynb（完整分析代码与报告）
├── 用户行为分析.csv（原始数据集，需自行下载）
└── README.md（项目说明文档）
 
 
## 核心功能模块
 
### 数据加载与存储
 
- 基于 SQLite 内存数据库（ :memory: ）实现数据快速读写
- 支持将 Pandas DataFrame 快速写入数据库，通过 SQL 完成多维度统计查询
- 封装统一数据查询函数，管理 SQL 执行逻辑
 
### 全链路转化漏斗分析
 
- 计算「首页 → 商品列表 → 商品详情 → 支付页面 → 订单确认」全链路各环节用户量
- 输出单环节转化率、流失率、整体转化率核心指标
- 绘制居中漏斗图，直观呈现用户逐层流失趋势
 
### 流失环节诊断
 
- 按流失率对各转化环节进行降序排名
- 三级严重度分级：严重（>50%）、中等（30%-50%）、轻微（<30%）
- 自动定位流失最严重的核心环节，输出优化优先级建议
 
### 用户多维度画像
 
- 新老用户对比：新/老用户转化能力差异量化分析
- 流量渠道分析：各来源渠道的流量规模与转化率排名
- 年龄性别画像：不同年龄段、性别的用户转化差异对比
 
### 可视化输出
 
- 新老用户转化率对比柱状图
- 各流量渠道转化率横向条形图
- 各年龄段-性别转化率折线图
- 全链路转化漏斗图
 
## 环境依赖

- sqlite3：Python内置模块，无需安装   
- pandas、numpy、matplotlib
  
## 运行步骤
 
- 使用 Jupyter Notebook 打开  电商用户行为画像与转化漏斗分析.ipynb
- 按顺序执行单元格，依次完成：工具库导入 → 中文字体配置 → 数据加载入库 → 各模块分析 → 可视化输出
- 最终查看各分析结论与图表
 
## 注意事项
 
- 项目默认使用 SQLite 内存数据库，重启 Kernel 后数据会清空，适合临时分析与练习
- 中文字体默认适配 Linux 环境（文泉驿微米黑），Windows 环境可修改为  SimHei 
- Matplotlib 版本低于 3.4 时， ax.spines  不支持列表传参，需拆分为单行设置
 
## 核心分析结论示例
 
- 整体转化表现：全链路整体转化率 3.78%，用户从浏览到下单流失显著
- 核心流失节点：「商品详情 → 支付页面」环节流失率最高（78.0%），是转化优化的第一优先级
- 用户差异：老用户转化率约为新用户的 2.4 倍，用户留存与复购运营价值更高
- 渠道差异：不同流量渠道转化率差距明显，可针对性优化低质量渠道投放
